# Project 3: SQL Data Analysis

For this project, I used SQL to explore and analyze the dataset. Working with SQLite and DB Browser for SQLite helped me understand how data can be retrieved, filtered, sorted, and summarized using queries.

## Tools Used

* SQLite
* DB Browser for SQLite

## SQL Concepts Practiced

* SELECT
* WHERE
* ORDER BY
* GROUP BY
* COUNT()
* AVG()
* SUM()

## Analysis Performed

As part of this project, I worked with different SQL queries to explore the dataset and understand the information it contained.

* Retrieved data from the dataset using SELECT statements.
* Filtered specific records using WHERE conditions.
* Sorted data using ORDER BY to organize the results.
* Used GROUP BY to summarize data across different categories.
* Applied functions such as COUNT, AVG, and SUM to perform basic analysis.
* Practiced writing queries to answer different questions based on the dataset.

## What I Learned

Through this project, I learned the basics of working with SQL and databases. I gained hands-on experience writing queries and using different SQL clauses to analyze data. This project helped me understand how SQL can be used to work with large datasets and extract meaningful information efficiently.
